# Automation hh (aka ahh!)
Это модульное приложение браузерной автоматизации для сайта hh.ru.
Меня бесит что для созвона нужно делать по 50 откликов, мне есть чем заняться :)

### Зачем это нужно?
- Отклики на вакансии
- Подъем резюме
- Написание сопроводительных писем (на основании вакансии)
- Ответы на вопросы рекрутеров
- Работа с несколькими аккаунтами
- Агрегация по настоящему важных сообщений
